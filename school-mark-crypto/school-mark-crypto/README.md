# School Mark Crypto

## Project Description
A school project that demonstrates a cryptographic system for handling school marks.

## Requirements
- Node.js
- npm

## Installation

1. Clone the repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file if required and configure the necessary environment variables.

## Run the Project

```bash
node server.js
```

If your project requires the legacy OpenSSL provider:

```bash
node --openssl-legacy-provider server.js
```

## Notes
Do not upload `.env` files containing passwords, API keys, or other secrets.
